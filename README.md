# Claude Chats

Historial de conversaciones con Claude, organizado por proyecto y tema.

Sirve para consultar decisiones, soluciones y contexto desde cualquier equipo.

## Estructura

```
Claude Chats/
├── AZCKeeper/          # Chats del proyecto AZCKeeper
├── Kelsie_App/         # Chats del proyecto Kelsie App
├── General/            # Chats generales o multi-proyecto
└── README.md
```

## Convenciones

- Un archivo `.md` por conversacion o tema
- Nombre: `YYYY-MM-DD_tema-breve.md`
- Ejemplo: `2026-04-07_setup-github-sync.md`
